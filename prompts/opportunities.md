---
description: Systematically identify and rank project improvement opportunities
argument-hint: "[focus]"
---

Identify the best opportunities to improve the current project. Use `$ARGUMENTS`
as an optional focus.

Reconstruct the current project state from code, tests, documentation, recent
history, plans, and observed behavior. Separate facts, strong inferences, stated
intentions, and speculation.

Consider user value, reliability, safety, experience, maintainability,
operations, and new capabilities. Keep three to five credible candidates. For
each candidate, state:

- Problem and repository evidence
- Expected user or project value
- Estimated effort and dependencies
- Main risks and unknowns
- Confidence

Rank the candidates by value, urgency, evidence, effort, risk, and dependency.
Recommend one next opportunity and explain why it comes first. Put unsupported
or lower-value ideas in a short deferred list. Do not create a roadmap, ticket,
plan, or code change.

# Direct Assistance

Use this workflow for small requests with no project edit, remote write,
personal-data access, or external side effect.

- Select this workflow explicitly with `select_workflow`.
- Use only nonsensitive local reads and safe one-command checks.
- Do not edit files, create artifacts, access personal data, or perform remote actions.
- Hand off when the request needs a different deliverable or authority.
- Answer directly with no goal, stages, or decision preamble. Do not use the report structure in chat.
- Write in friendly professional tone per the communication contract in `AGENTS.md`. Also avoid comprehensive, crucial, and it is important to note.
